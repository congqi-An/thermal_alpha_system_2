## 一、条纹图像预处理

### 1.1 红通道提取与下采样

输入：海康相机 RGB 帧（MV_CC_GetImageForRGB）→ **取红通道** `frame[:,:,0]` → 下采样至 256×256（CNN 输入）。
目的：降低计算量，保留空间结构信息。**取红通道而非 RGB 灰度化是波长选择性**——He-Ne 632.8nm 条纹能量集中在红通道，直接丢弃非红光杂色噪声，SNR 最高。条纹空间频率远低于像素奈奎斯特极限，下采样不损失信息。

### 1.2 背景归一化

干涉图实际光强：$I_{raw}(x,y) = B(x,y) + A(x,y)\cos[\phi(x,y)] + n(x,y)$
- B: 不均匀背景（光源高斯分布、暗电流）
- A: 调制度（对比度包络）
- φ: 相位（携带测量信息）
- n: 噪声

预处理目标：去除 B，归一化 A，保留 φ。
方法：百分位滤波估计背景 → 减去 → 裁剪归一化到 [0,1]。

### 1.3 条纹可见度（质量指标）

Michelson 可见度定义：

$$V = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$$

局部可见度反映该区域条纹是否清晰可辨。V→1 表示高对比度，V→0 表示条纹消失。
本系统用 CNN 学习从全图直接回归质量分数 q∈[0,1]，替代逐像素计算 V 再聚合。

## 二、FrameAnalysisNet 架构

### 2.1 设计思路

三头统一网络，单次前向推理同时输出：
- 光心 (cx, cy)：条纹环中心坐标
- ROI 半径 (r0_1, r0_2, r0_3)：最佳采样半径
- 帧质量 quality：[0,1] 标量

输入：(B, 1, 256, 256) 灰度帧。

### 2.2 主 Encoder（空间结构提取）

```
Conv(1→32, k3, s2) → BN → ReLU
Conv(32→64, k3, s2) → BN → ReLU
Conv(64→128, k3, s2) → BN → ReLU
Conv(128→256, k3, s2) → BN → ReLU
```

4 次 stride=2 下采样：256→128→64→32→16。感受野覆盖全图。
每层通道翻倍：捕获从边缘到全局的多尺度特征。

### 2.3 光心头 / R0 头

光心头为 **v2 热图回归**（v1 的 GAP+FC 因空间维被平均化，定位天花板仅 ~136px，已弃用）：

```
光心头 v2: Conv(256→64, k3) → ReLU → Conv(64→1, k1) → 16×16 空间热图
           → softmax 期望(soft-argmax) → (cx, cy) ∈ [0,1]  [亚格点插值]
R0 头:     GAP → Flatten → FC(256→64) → ReLU → FC(64→3) → Sigmoid → (r0₁,r0₂,r0₃)
           → 排序 + 最小间距 40px 约束 → 全分辨率采样半径
```

- 热图保留空间位置信息，softmax 期望做亚格点插值，定位精度显著优于 v1 的全局池化回归
- R0 头输出 3 个候选半径（分散选取，提高鲁棒性）
- R0×3 现直接作为相位计数采样环（`ring_mode=cnn`）：半径铺得宽 → φ(s) 外推基线长 → 计数更准
- 光心/ROI 判定模式前端可切 **cnn / cv**（cv 为峰谷镜像对称精化 + 径向 std 能量检测兜底）

### 2.4 质量头（MobileNetV3 风格）

采用 InvertedResidual（倒残差）模块：

```
1×1 Conv 扩展通道 (expand_ratio=3) → 3×3 深度卷积 → 1×1 Conv 压缩
```

关键设计：
- **深度可分离卷积**：3×3 depthwise + 1×1 pointwise，参数量仅为标准卷积的 1/9
- **倒残差**：先扩展再压缩（与标准残差相反），低维表示间跳跃连接保留信息
- **线性瓶颈**：压缩层不加激活，避免低维空间信息损失

4 个 InvertedResidual block → GAP → FC → Sigmoid → quality∈[0,1]

### 2.5 训练策略

- 标签来源：人工标注质量分 + 退化负样本（散焦/对比度塌缩/重噪）重训质量头
- 损失：MSE（回归）
- 数据增强：旋转、亮度抖动、高斯噪声
- 推理速度：<2ms/帧 (GPU)

## 三、条纹计数：带符号空间相位解调

本系统计数已从"时序过零/峰谷计数"升级为"带符号空间相位解调"。根本原因：
单点或单环的亮度时序是 $I(t)=B+A\cos[\phi(t)]$ 型，$\cos$ 偶对称、**不含相位方向**，
加热首尾"又吞又吐"的往复段会把 −1 个条纹数成 +1（旧过零法必然虚计）。
空间相位法从**半径维**取方向，往复自动抵消。

### 3.1 椭圆-极坐标展开

以光心 (cx,cy) 为心，把每帧展开到极坐标 (θ, s)，径向按 $s=r^2$ 均匀采样。
物理依据：牛顿环/等倾环相位 $\phi \propto r^2$，按 $s=r^2$ 采样后径向剖面近**单频正弦**，
利于窄带解调。

### 3.2 角向中值抗遮挡

斜网格观察屏的暗网格线、边缘暗角只遮少数角度。沿角向 θ 取**中值**（nanmedian）
天然剔除这些遮挡，得干净的一维径向剖面 line(s)；静态遮挡另用掩膜预剔除。

### 3.3 窄带解析信号 → 空间相位

对径向剖面做 FFT，围绕空间基频 $f_0$ 窄带带通 + 逆变换得解析信号 $Z(s)$，
其相位 $\phi(s)=\angle Z$ 即空间相位。带通同时滤除饱和削顶产生的谐波。

### 3.4 CNN 三环采样 + 时间解缠绕

采样通道取 CNN 三头输出的 r0×3（`ring_mode=cnn`，默认）或解调幅值自选（`cv` 兜底）。
每个采样环沿**时间维**对 $\phi$ 做 `np.unwrap` 解缠绕得连续相位时序。
CNN 三环半径铺得宽，为下一步 $\phi(s)$ 外推提供长基线。

### 3.5 Theil-Sen 拟合 + 截距外推

每帧对多环的解缠绕相位做稳健线性拟合 $\phi(s)=\phi_0 + k\cdot s$（Theil-Sen 抗离群）。
截距 $\phi_0$ 外推到中心 $s=0$，即中心处相位。条纹计数：

$$N(t) = \frac{\phi_0(t) - \phi_0(0)}{2\pi}$$

带符号（吐 +1 / 吞 −1），往复自动抵消，天然含小数精度。斜率项 $k(t)$ 吸收
条纹间距随温度的时变，不污染计数。

### 3.6 中心稳定性（对计数精度决定性）

极坐标中心一旦逐帧抖动，采样环表观半径整体偏移，注入虚假 $\Delta\phi_0$。
故中心必须稳定：热身期 CNN 光心取中值锁定 + EMA 温和跟随（跟慢热漂移、平滑抖动），
而非逐帧硬跟随。实测：中心逐帧硬跟随或周期硬重锁会因 CNN 光心 ~9px 偏差与抖动漏计。

## 四、CNN 图像回归通用理论

### 4.1 回归 vs 分类

分类：输出离散标签（softmax）。回归：输出连续值（sigmoid/linear）。
本系统质量评分是回归问题：q∈[0,1] 连续。

### 4.2 全局平均池化（GAP）

将 H×W×C 特征图 → 1×1×C 向量（每通道取空间均值）。
优势：
- 替代全连接层，参数量从 H×W×C×N 降至 C×N
- 引入空间不变性：条纹平移不影响质量判断
- 防过拟合（无额外参数）

### 4.3 轻量部署考量

| 指标 | FrameAnalysisNet | 说明 |
|------|-----------------|------|
| 参数量 | ~630K | 主 encoder + 3 头 |
| 推理延迟 | <2ms/帧 (GPU) | 20fps 全链路 <50ms |
| 输入 | 256×256×1 | 灰度单通道 |
| 输出 | 6 个标量 | cx,cy,r0×3,quality |
| 推理频率 | 每帧 (20fps) | 实时 |

设计约束：必须与主测量链路（温控/扫描）共享 GPU，不能占用过多显存/算力。

## 五、深度学习条纹分析前沿（Feng 2019 综述要点）

### 5.1 CNN 用于条纹去噪

FPD-CNN (Lin 2020)：多阶段卷积网络，输入含噪条纹图 → 输出干净条纹图。
比传统窗傅里叶滤波(WFF)更快且保边效果更好。

### 5.2 CNN 用于相位提取

传统：相移法(需多帧) / 傅里叶变换法(单帧但精度有限)。
深度学习方法：端到端从单帧条纹图直接回归相位分布，精度接近 12 步相移。

### 5.3 CNN 用于条纹质量评估

传统：逐像素计算 V → 统计聚合。
深度学习：直接学习"人眼感知质量" → 更贴合实际判断（如局部缺陷、偏心等）。
本系统 QualityNet 属此类。

### 5.4 本系统定位

本系统计数采用**空间相位解调**（非过零计数、也非 CNN 端到端相位回归）。CNN 提供：
- 光心种子（极坐标展开中心，经 EMA 稳定；替代 Hough，更快更鲁棒）
- 采样半径 r0×3（直接作为相位解调采样环，宽半径基线利于 φ(s) 外推）
- 质量门控（决定是否可信计数，触发 Agent 调参）
相位解调本身由经典信号处理完成（FFT 窄带 + 时间解缠绕 + Theil-Sen 外推）。
