# 光路搭建与调节指导知识库

> 知识来源: 本实验原始讲义《干涉法测量固体的线膨胀系数》光路调节章节 + 本系统实测经验
> 本文档是 Agent 回答光路类问题的权威依据。仪器命名与原始讲义保持一致。

---

## 一、实验光路结构

### 1.1 仪器组成（原始讲义命名）

线膨胀实验仪的测量光路是一个迈克尔逊干涉仪，元件命名如下：

- **氦氖激光器**：功率约 1mW，波长 632.8nm（可选半导体激光器 650nm）
- **扩束镜**：短焦透镜，把细激光束扩成发散球面波，是看到干涉圆环的关键元件
- **分束镜**：半透半反，把光分成两臂
- **反射镜1、反射镜2**：两个固定反射镜，各在一条臂上，带倾斜微调螺丝
- **反射镜3（动镜）**：通过螺纹与试件连接，试件热膨胀时顶推它平移——它就是迈克尔逊干涉仪的"动镜 M1"
- **温控炉**：加热试件，适宜升温范围室温~60℃，测温最小分辨率 0.1℃
- **毛玻璃屏 / 工业相机**：观察干涉图样的位置（本系统用海康 MV-CS050-60GC 工业相机替代人眼观察）

### 1.2 对应关系

| 原始讲义命名 | 迈克尔逊标准命名 | 作用 |
|------|------|------|
| 反射镜3（动镜） | M1 动镜 | 被试件顶推，位移 ΔL 即试件伸长量 |
| 反射镜1 / 反射镜2 | M2 定镜及折叠镜 | 构成参考臂 |
| 分束镜 | G1 分束器 | 分振幅双光束 |
| 扩束镜 | 扩束透镜 | 产生扩展光源，形成等倾圆环 |

反射镜3 经分束镜成像与参考臂虚像构成等效空气膜，膜厚 h 随试件膨胀变化，这是条纹吞吐的根源。

### 1.3 试件安装（光路搭建的前置步骤）

1. 用游标卡尺测量并记录试件长度 L₁（黄铜 H62，标称 150mm，直径 18mm）
2. 用 M4 螺钉旋入试件一端螺纹孔，手提螺钉把试件放入温控炉
3. 确保试件测温孔与炉侧面测温探头插入圆孔对准；轻放，禁止试件直接掉进炉内（会砸碎底端石英玻璃垫）
4. 拧下 M4 螺钉，将带螺纹的反射镜3（动镜）与试件连接——**不可拧得过紧**，以免动镜上的石英玻璃管破碎
5. 将 PT100 测温探头经炉侧面圆孔插入试件测温孔，插头接仪器后面板 PT100 接口
6. 温控炉控制电源接后面板温控炉电源输出接口
7. 更换试件时：先拧下反射镜3，再用 M4 螺钉取出试件

## 二、光路调节步骤（原始讲义标准流程）

### 2.1 第一步：不加扩束镜，用光点重合做粗调

1. 接通电源，点亮氦氖激光器（半导体激光器则接仪器右侧 5V 激光电源）
2. **先移开扩束镜**——此时激光是直径约 1mm 的细平行光束
3. 调节激光器出射方向、反射镜1、反射镜2 和分束镜的方位
4. 观察毛玻璃屏：屏上会出现**两组光点**（分别来自两臂的多次反射）
5. 目标：使两组光点中**两个最亮的光点完全重合**
6. 两个最亮点重合意味着两臂的主反射光束共轴，为加入扩束镜后出现干涉条纹创造条件

**这一步看不到任何干涉条纹**——因为没有扩束镜就没有扩展光源，只有光点。这是正常现象，不是故障。

### 2.2 第二步：加入扩束镜，获得干涉条纹

1. 将扩束镜放入光路：
   - 半导体激光器：通过扩束镜调节架放置并调节位置
   - 氦氖激光器：将带磁性的扩束镜架吸附在激光器出光口上
2. 仔细调节扩束镜位置，毛玻璃屏上将出现干涉条纹（同心圆环）
3. 微调反射镜1 和反射镜2 的倾斜螺丝，把干涉环调到屏上便于观察的位置
4. 本系统中观察位置由工业相机承担：环应调到相机视场中央，环纹对称

### 2.3 调节成功的判据

- 屏/相机视场中出现**明暗相间的同心圆环**（等倾干涉条纹）
- 圆环中心位于视场中央，环纹左右上下对称
- 条纹对比度好：亮环亮、暗环暗，明暗分明
- 加热时圆环有节奏地从中心涌出（吞吐），说明光路工作正常

## 三、扩束镜前后可观察到的现象

### 3.1 未加扩束镜时的现象

| 现象 | 物理解释 |
|------|----------|
| 毛玻璃屏上只有分立的小光点，呈两组分布 | 细激光束在两臂各经历多次反射/透射，每个界面产生一个光点 |
| 两组光点中最亮的两个可以调节重合 | 最亮点是两臂主反射光，重合即两臂主光路共轴 |
| **看不到任何干涉条纹/圆环** | 光束太细（约1mm），只照亮等效空气膜上一个点，无法形成空间分布的干涉图样 |
| 光点亮度很高、边缘锐利 | 激光未经扩束，能量集中，功率密度大 |

要点：**未加扩束镜阶段的任务只是"对光路"（让两个最亮光点重合），不是"看条纹"。此时没有条纹是完全正常的。**

### 3.2 加入扩束镜后的现象

| 现象 | 物理解释 |
|------|----------|
| 屏上出现明暗相间的同心圆环 | 扩束镜把点光源变成发散球面波，不同倾角 θ 的光线经等效空气膜干涉，同倾角光线会聚成同一级圆环（等倾干涉） |
| 圆环内疏外密 | 角间距 dθ = λ/(2h·sinθ)，θ 越大环越密 |
| 环心可能是亮斑也可能是暗斑 | 取决于中心处光程差 2h 是波长的整数倍还是半整数倍 |
| 微调反射镜1/2 倾斜螺丝，环心移动、环纹变形 | 倾斜改变两臂波前的相对夹角，等效空气膜出现楔角 |
| 两镜不平行时圆环变椭圆甚至变直条纹 | M1 与 M2' 有夹角时从等倾干涉过渡到等厚干涉 |
| 加热试件时圆环从中心一圈圈涌出（吞吐） | 试件膨胀顶推动镜，h 每增 λ/2≈316nm 涌出一条新环 |
| 停止加热、温度回摆时条纹可能反向缩进 | 热胀冷缩可逆，h 减小时条纹缩入——这正是需要带符号计数的原因 |
| 屏上可能伴随散斑和灰尘衍射斑 | 激光相干性强，光学面灰尘/瑕疵产生衍射杂斑，不影响计数但提示需清洁 |

要点：**扩束镜是"从光点变成圆环"的开关。** 加入扩束镜后若仍无圆环，回到第一步检查两个最亮光点是否真的重合。

### 3.3 本系统（相机观测）的补充现象

- 不加扩束镜时让相机直对激光，传感器只收到一个极亮的饱和光斑，测不到任何条纹信息，且长时间可能损伤传感器——因此**系统测量时扩束镜必须在光路中**
- 扩束后光强摊开，相机需要足够曝光（本系统默认曝光 20000μs、Gamma 0.7）才能看清条纹
- 相机画面中条纹的清晰程度由 CNN 质量分实时反映（0~1，>0.6 为佳）；调曝光/Gamma 后约 3 秒生效

## 四、常见光路故障诊断

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 加了扩束镜仍无条纹 | 两最亮光点未真正重合；扩束镜离出光口太远/太近 | 移开扩束镜重新对光点；微调扩束镜轴向位置 |
| 条纹很淡、对比度低 | 两臂光强相差大；环境杂散光强；扩束镜偏心 | 调分束镜角度均衡两臂；遮光；把扩束镜调至光束正中心 |
| 圆环偏心、不对称 | 反射镜1/2 倾斜未调好 | 微调倾斜螺丝使环心移到视场中央 |
| 圆环变成椭圆/斜条纹 | 两镜不平行（出现楔角） | 微调使 M1∥M2'，恢复同心圆 |
| 条纹模糊抖动 | 环境振动、气流扰动 | 避免触碰实验台、关风扇门窗，等稳定后再计数 |
| 加热时条纹不动 | 试件未顶住动镜；动镜螺纹连接松脱；温控未生效 | 检查反射镜3与试件连接；确认温控 SV 已设、PV 在升 |
| 条纹吞吐方向反复 | 温度在设定点附近回摆（负反馈控制特性） | 避开温控整定区间，或等稳定后再计数（本系统 NRateGate 与带符号计数已自动抵消往复） |
| 相机画面全白 | 曝光过长或激光未经扩束直射 | 降曝光；确认扩束镜在位 |
| 相机画面全黑 | 未取流、曝光过短、光路被挡 | 检查取流状态、曝光设置、光路遮挡 |

## 五、光路相关安全注意事项

1. **眼睛不可直视激光束**（包括扩束后的发散光）
2. 反射镜3（动镜）上的石英玻璃管不能承受较大扭力和拉力，拧接试件时不可过紧
3. 温控炉中试件底部的石英玻璃垫不能承受较大冲击，务必轻拿轻放
4. 温控炉温度不可设置太高（本系统安全上限 80℃，实验讲义建议升温不超过 60℃），以免冷却时间过长
5. 反射镜和分束镜均为易碎器件，调节倾斜螺丝时动作要轻
6. 需保证实验环境安静，避免振动干扰条纹
