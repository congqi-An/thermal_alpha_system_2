## 一、固体的线膨胀系数

### 1.1 定义与基本公式（讲义式1-式3）

绝大多数固体热胀冷缩。原长 L₀ 的固体受热温度升高 Δt，伸长量 ΔL 与 Δt 成正比、与原长 L₀ 成正比：

$$\Delta L = \alpha L_0 \Delta t \quad (\text{式1})$$

此时总长 $L_t = L_0 + \Delta L$（式2）。α 即**线膨胀系数**，是材料的基本物理参数，温度变化不大时可视为常数。

α 的物理意义：温度每升高 1℃，固体伸长量与其原长之比。温度变化较大时 α 可用温度的多项式描述（α = A + Bt + Ct²，A、B、C 为常数）。

### 1.2 平均线膨胀系数（讲义式4）

实际测量中，测得室温 t₁ 下长度 L₁ 与温度 t₂ 下长度 L₂（或两者间长度变化量 ΔL = L₂ − L₁），平均线膨胀系数：

$$\alpha = \frac{\Delta L}{L_1 (t_2 - t_1)} = \frac{\Delta L}{L_1 \Delta T} \quad (\text{式4})$$

本实验直接测量量：ΔL、L₁、t₁、t₂。

### 1.3 本实验参考值

| 试件 | 线膨胀系数参考值 | 适用温区 |
|------|------------------|----------|
| 黄铜 H62 | α = 20.8×10⁻⁶/℃ | 25~300℃ |
| 硬铝 | α = 23.2×10⁻⁶/℃ | 20~300℃ |

试件尺寸：长度 L = 150mm，直径 18mm。仪器系统误差小于 3%。

微观解释：温度升高 → 晶格原子热运动加剧 → 原子间势能非简谐效应使平均间距增大 → 宏观膨胀。金属的 α 量级为 10⁻⁵/K。

## 二、干涉法测 ΔL 的原理（讲义式5-式6）

### 2.1 迈克耳孙干涉测长（式5）

长度 L₁ 的试件在温控炉中从 t₁ 升温到 t₂，线膨胀伸长 ΔL 顶推迈克耳孙干涉仪动镜（反射镜3），动镜位移量 ΔL 与干涉条纹变化级数 N 成正比：

$$\Delta L = N \cdot \frac{\lambda}{2} \quad (\text{式5})$$

λ 为激光波长（He-Ne 632.8nm）。物理图像：动镜每移动 λ/2 ≈ 316nm，等效空气膜厚 h 变化 λ/2，光程差变化一个波长，视场中恰好吞吐一条条纹。

### 2.2 线膨胀系数公式（式6）

式5 代入式4：

$$\alpha = \frac{N\lambda}{2 L_1 \Delta T} \quad (\text{式6})$$

数值验证：α_ref=20.8×10⁻⁶/K，L₁=150mm，ΔT=5℃ → N = 2αL₁ΔT/λ ≈ 49 条。即每升温 5℃ 约吞吐 49 条，本系统实测各段 N≈51~53（默认步长 5℃）与之同量级。

### 2.3 两种测量方式（讲义实验内容）

1. **定伸长测温度**：数到预定条纹数（如 50 或 100 环变化），记录温升 ΔT
2. **定温升测伸长**：升温固定值（如 5℃ 或 10℃），数对应条纹变化 N

本系统自动扫描采用方式2 的分段版本：30→50℃ 每 5℃ 一段（默认），逐段计 N 算 α。

## 三、等倾干涉的物理图像

### 3.1 等效空气膜与光程差

迈克耳孙干涉仪中，动镜 M1（反射镜3）与定镜经分束镜所成虚像 M2' 构成等效空气薄膜（膜厚 h）。当 M1 ∥ M2' 时为等倾干涉：

光程差：$\Delta = 2h\cos\theta$（θ 为光线倾角）

光强分布：$I(\theta) = 4I_0\cos^2\left(\dfrac{2\pi h\cos\theta}{\lambda}\right)$

亮纹条件：$2h\cos\theta = k\lambda$，中心级次最高 $k_{max} = 2h/\lambda$。

### 3.2 同心圆环的形成

扩束镜产生的发散球面波包含各种倾角的光线；同一倾角 θ 的光线会聚成同一级条纹 → 等倾线是同心圆环。环内疏外密（角间距 dθ = λ/(2h·sinθ)）。

### 3.3 条纹吞吐方向与符号

- h 增大（升温膨胀）→ 中心级次升高 → 新条纹从中心**涌出**（吐）
- h 减小（降温收缩）→ 条纹向中心**缩入**（吞）

温控在设定点附近回摆时吞吐方向会反复。**带符号计数**（本系统空间相位法）使涌出计 +1、缩入计 −1，往复自动抵消，净计数只反映真实净膨胀——这是相对旧过零法的关键改进。

### 3.4 条纹可见度

Michelson 可见度 $V = (I_{max} - I_{min})/(I_{max} + I_{min})$。影响因素：两臂光强均衡度、杂散光、光学面清洁度、相干性。He-Ne 激光相干长度远大于实验光程差范围，相干性不是限制因素；实际可见度主要受光强调节与杂散光影响。本系统用 CNN 质量头实时回归质量分 q∈[0,1] 作为可见度的工程化度量。

## 四、深层物理推理素材（供 Agent 解释异常与误差）

### 4.1 为什么计数用固定半径而不数中心

中心吞吐 N 条 ⟺ 任意固定半径处光强完成 N 个明暗周期（物理等价）。固定半径采样的优势：不受环心漂移影响、可用多半径冗余互检。本系统取 CNN 选定的 3 个采样半径（r0×3），在 s=r² 坐标下干涉信号是单频余弦，可用傅里叶变换法（FTM）严密解调相位。

### 4.2 s=r² 坐标变换的物理含义

小角近似 cosθ ≈ 1 − θ²/2，令 s = r²，则 I(s) ∝ 1 + cos(2πf₀s + φ₀)，其中相位 φ₀ = 4πh/λ 直接对应中心光程差。h 变化 λ/2 → φ₀ 变化 2π → N = Δφ₀/2π。这个变换把"牛眼环"变成标准单频信号，是空间相位计数在数学上严密的根基。

### 4.3 主要误差来源（深层推理）

| 误差源 | 机制 | 量级 | 对策 |
|--------|------|------|------|
| 温度测量 | PT100 测的是试件测温孔温度，PV ≠ 试件表面/平均温度；炉温梯度 | 主导项，小 ΔT 段可达 ~10% | 分段 ΔT 用实测 PV 起止值；避免过小 ΔT 段 |
| 条纹计数 | 振动引起伪吞吐；温度回摆往复；光心漂移致外推截距偏移 | σ_N ≈ 0.5~1 条 → 3~5% | 带符号计数抵消往复；NRateGate 限速；光心 EMA 稳定跟随 |
| 试件长度 | L₁ 游标卡尺测量 | σ_L ≈ 0.5mm → <0.5% | 可忽略 |
| 接触传动 | 试件与动镜螺纹连接存在间隙/预紧不均，膨胀未完全传动 | 首段偏大常见 | 首段进段确认；检查连接 |
| 环境 | 振动、气流、温度漂移 | 条纹抖动、质量分下降 | 安静环境；等稳定再计数 |
| 避开温控整定区 | 负反馈控制在设定点反复 → 条纹涌出缩进交替 | 计数困难（讲义明确提示） | 设定温度避开测量窗口，或等稳定后计数 |

误差传播：$\sigma_\alpha/\alpha = \sqrt{(\sigma_N/N)^2 + (\sigma_{\Delta T}/\Delta T)^2 + (\sigma_L/L)^2}$

### 4.4 常见现象的物理追问

- **"为什么 α 偏大？"** → 多半是 ΔT 偏小被放大：段起止温度标签不准、PV 未真实到温就结算、首段从室温起累计。其次 N 虚高（振动伪计数）。
- **"为什么升温时条纹短暂反向？"** → 样品/炉体热惯性不同步，或温控过冲后回摆；带符号计数会自动抵消，无需人工干预。
- **"为什么环越往外越密？"** → 角间距与 sinθ 成反比（dθ = λ/(2h·sinθ)）。
- **"为什么换曝光后条纹计数更稳？"** → 曝光决定信号对比度与饱和裕量：过暗则信噪比低、相位解调噪声大；过饱和则削顶失真。最佳为亮暗分明不饱和。
